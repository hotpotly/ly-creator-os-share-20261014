## 本地检查

```bash
dart format lib test
dart analyze lib test
flutter test
flutter build apk --release
./scripts/smoke-release-apk.sh
```

当前Flutter在包含中文字符的工程绝对路径下执行`flutter analyze`可能触发Analysis Server的LSP长度解析错误；`dart analyze lib test`使用同一分析规则且可正常完成。不要为了绕过问题把工程复制到项目外。

`smoke-release-apk.sh`会把正式release APK安装到已启动的后台Android模拟器，并验证它真正离开系统启动图、进入首页或首次设置界面。正式交付不能只验证debug、APK构建成功或进程存活，必须执行这项release可交互界面检查。

## 当前连接方式

1. Mac端打开`设置→Android快速记录`并开启局域网接收。
2. Android通过Bonjour发现Mac，不填写IP、端口或同步码。
3. 两端显示相同6位数字，用户在Mac确认后建立长期设备信任。
4. 手机记录先进入本地队列；收到Mac持久化最终回执后才显示`已同步`。

设备密钥保存在Android安全存储中。构建产物位于`build/app/outputs/flutter-apk/`，由`.gitignore`排除；APK、本机密钥、真实记录和附件不得提交Git。
