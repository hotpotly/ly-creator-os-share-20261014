# 分享隐私核验

审查日期：2026年10月14日。目标是分享最新Mac／Android源码及图文说明，不分享作者的真实业务数据。此说明描述本次范围，不构成对以后新增文件的永久安全保证。

## 包含什么

- Mac与Android源码、依赖锁文件、数据库结构／迁移和测试代码。
- App内置图标、植物插画、带来源说明的白噪音等功能静态资源。
- 安装说明、待办操作手册和12张新拍的演示截图。
- 测试中明确虚构的任务、金额、示例邮箱与占位凭据。它们用于验证功能，不是作者的账户、商单或真实交易。

## 没有上传什么

- 原开发仓库的Git提交历史和作者的提交身份信息。
- App用户目录、SQLite数据库及日志、备份、真实附件、收入原件、合同和发票。
- 作者真实商单金额、报价、客户文案、项目脚本与发布账号资料。
- API key、Token、Cookie、私钥、Android签名、Apple证书和本机配置。
- 私有APK、DMG、Whisper运行时／模型、node_modules、构建缓存和测试运行数据。
- 历史App截图、视觉基线、原型、内部需求／计划／接力和审查记录。
- 未提交、未验收的个人工作区改动。

## 如何处理

1. 从最新已提交代码生成独立源码快照，不把原仓库连接到分享仓库，也不推送原历史。
2. `git archive`按导出规则排除内部文档和历史图片；分享目录重新初始化Git。
3. 扫描路径、密钥格式、已知私人标记、凭据URL、数据库／签名／安装包扩展名，拒绝符号链接和未审查大文件。
4. 人工复核剩余邮箱、电话、用户路径、内网地址和凭据赋值命中，确认是测试占位值、示例URL或本地地址安全规则；没有把这些功能规则误删。
5. 文案导入测试的Word文件已检查内部文字，是通用导入样例。App示例seed内的三段文案在导出时统一替换为“虚构演示文案”，不是发送原示例段落。除测试样例脱敏外，不改产品功能逻辑。
6. 说明图来自本次新建的独立测试数据库，禁用旧演示seed，只建立“演示项目：书桌整理”等虚构记录；没有读取日常用户数据库，也没有拿旧截图打码冒充干净数据。
7. 检查说明书图片引用、截图内容和快照构建；上传前确认目标仓库为Private，上传后复核远端提交及可见性。

## 仍需注意

GitHub私有仓库不提供“任何拿到链接的人都能看”的匿名私密链接，好友需要账号及邀请。授权成员仍可下载并保留副本，请只邀请信任的人。

源码保留产品品牌“LY Creator OS”、包标识和通用产品规则，不承诺匿名隐藏作者的GitHub用户名。作者的真实工作数据不属于源码。

自动扫描不能保证发现未来加入的所有隐私。以后更新仍需重新审查新增文案、二进制文件、截图和Git历史。不要把本次干净分享仓库的远程地址加到原开发仓库后直接推送历史。
